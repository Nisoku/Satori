Welcome to the Satori Guide! These comprehensive guides will help you master the advanced features of Satori for building observable applications.

Getting Started

If you’re new to Satori, start with our Quick Start guide to get up and running quickly.

Core Concepts

State Watching

Learn how to automatically track and log state changes with Satori’s powerful watcher system. Create watchers that detect changes and log them automatically.

Causal Linking

Discover how to trace cause-and-effect relationships between events, building causal chains for better debugging and analysis.

Filtering Events

Master Satori’s comprehensive filtering API to query events by level, scope, tags, time ranges, and custom criteria.

Advanced Features
